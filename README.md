## 📌 Project Status

This project was developed for the Pleximus Hackathon 2026.

The application demonstrates:

- Gemini AI integration
- AI agent with tool calling
- Calculator tool
- Weather tool
- Wikipedia tool
- Text Utility tool
- Flask backend API
- HTML, CSS and JavaScript frontend

The Gemini API is subject to the quota and rate limits of the configured API key.
